This folder contains companion code, the datasets, and the appendix for ST-PCA. It includes 6 scripts:

1) It defines functions that are needed for ST-PCA to work.
2) Reproduces the analysis on the RNA dataset discussed in Section 5.2 of the paper. It requires the datasets "small_rna.csv", "tpca_rna_SI.csv", and "tpca_rna_SO.csv".
3) Reproduces the analysis of the Sunspots dataset discussed in Section 5.1 of the paper. It requires the datasets "Sunspotsfull_TPCA_SI.csv" and "Sunspotsfull_TPCA_SO.csv".
4) Reproduces the analysis of Section 4 of the paper (Numerical Experiments).
5) Defines a modification of a function in Script (1), to allow for the contour analysis of Subsection B.3 of the Supplementary Material.
6) Reproduces Subsections B.1, B.2, and B.5 of the Supplementary Material.

Dataset descriptions:

i) "small_rna.csv" contains the 7-dimensional angular RNA data.
ii) "tpca_rna_SI.csv" contains the scores obtained for the dataset in (i) through the SI variant of T-PCA.
iii) "tpca_rna_SO.csv" contains the scores obtained for the dataset in (i) through the SO variant of T-PCA.
ix) "Sunspotsfull_TPCA_SI.csv" contains the scores obtained for the (full) Sunspots dataset through the SI variant of T-PCA.
v) "Sunspotsfull_TPCA_SI.csv" contains the scores obtained for the (full) Sunspots dataset through the SO variant of T-PCA.

Finally, we include a PDF of our Appendix (STPCA_Supplementary_Material).
